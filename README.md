# Team Skill Matrix Graph

An interactive graph visualizing a team's skills, built with Next.js, React Flow, and plain CSS.

## Features
- **Interactive Graph:** Built with `@xyflow/react`.
- **Distinct Nodes:** People are styled in Brown, Skills in Blue.
- **Data Persistence:** Graph state is saved to `localStorage`.
- **Vanilla CSS:** No UI frameworks or CSS libraries are used. All styling is standard CSS.
